# 隐私与数据说明

POCKETPort 由 RAGG3D 发布，为本地运行的采集工具。没有项目方运营的接收服务器、账户系统或遥测上传。安装过程会从 Python 包索引下载依赖；使用应用时，手机请求仍会到达原应用服务。

- 用户在自己电脑上选择来源，启动 WireGuard 采集；目标 HTTPS 由电脑生成的 CA 解密。非目标 TLS 连接根据 SNI/目标 IP 透传；非目标业务响应不保存。IPv4 网络在隧道开启时经电脑转发。
- 保存目标域名的 JSON/JSONP 响应、来源、时间、HTTP 状态与路径。URL 的所有查询参数值会被替换。不保存请求头、请求体、响应头；响应 JSON 中名称匹配已知凭证字段的值会被替换。
- 字段名称过滤不是完整的个人信息匿名化。订单、姓名、地址、联系方式和不常见字段里的秘密仍可能存在。导出前请检查，不要公开提交数据目录。
- 本地目录 `~/.pocketport` 保存会话、独有的 CA 和 WireGuard 密钥。POSIX 权限按用户私有设置；Windows 使用当前用户目录的系统 ACL，不额外修改 ACL。
- 配对页面只监听 `127.0.0.1:8766`，API 需要本地随机令牌并校验 Host/Origin。配对私钥不作为 MCP 工具结果返回。UDP 51820 用于手机隧道。
- MCP 客户端可以读取采集结果。读取意味着数据进入所选 Agent 的上下文，是否进一步传到模型提供商取决于该客户端。导出工具本身只返回路径。
- 引擎错误日志存储在会话目录，仅供本地诊断。它可能包含网络错误元数据，插件不向 Agent 返回该日志。
- 默认 30 分钟停止隧道，单次保存上限 100 MB。软件不定时删除历史会话；用户可按手册卸载或删除数据目录。

只在自己控制的手机与获准访问的账户上使用。问题反馈请提供版本、操作系统与脱敏错误，不附二维码、连接配置、CA 私钥或真实业务响应。
