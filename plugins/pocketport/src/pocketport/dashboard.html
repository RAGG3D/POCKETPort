POCKETPort 口袋港

把手机里的信息，带给自己的 AI。

采集在你的电脑进行。你决定打开哪些页面，以及把结果交给谁。

1 · 开启采集

手机和电脑连接同一 Wi-Fi。自动建议的地址仍需核对。 其他小程序必须填写其实际后端域名；微信没有统一的数据采集域名。

2 · 手机扫码连接

  1. 在手机安装 WireGuard，选择「添加隧道 → 扫描二维码」，扫描上方二维码并开启。

  2. 首次使用：手机浏览器打开 http://mitm.it，安装这台电脑的证书。iPhone 还需在「设置 → 通用 → 关于本机 → 证书信任设置」开启完全信任。

  3. 打开所选 App，刷新、滚动列表，逐个打开需要的详情，观察左侧采集条数增加。

二维码和配置包含你的连接私钥，不要分享。连接期间 IPv4 网络经电脑转发。不要设置手机的 HTTP 代理。

3 · 停止并交给自己的 Agent

完成浏览后点击「停止采集」，并关闭手机 WireGuard。下载结果后，告诉自己的 Agent 你想怎么使用数据。

导出内容可能包含订单、地址和联系方式；分享前请检查。未打开的页面、缓存和加密不兼容的接口可能缺失。零条记录不代表没有数据。

连接遇到问题？

先确认同一 Wi-Fi、电脑没有休眠、UDP 51820 已被防火墙允许。mitm.it 打不开通常是网络连接问题；能打开但 App 报证书错误，可能是 App 不信任用户证书。停止采集并关闭 WireGuard 可恢复原网络路径。

Android 部分 App 不信任用户安装的 CA；此版本不提供绕过证书固定的功能。若数据一直为零，请查看下载包中的 docs/USER_MANUAL.zh-CN.md。
